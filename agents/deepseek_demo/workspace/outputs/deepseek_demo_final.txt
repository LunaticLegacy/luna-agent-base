## 2. Analysis

### 2.1 Architecture Research Findings

*Architecture constraints*: The researcher concluded that a single Transformer layer (MHSA + FFN) is the core building block. The MHSA component requires splitting the Q, K, V projections into `num_heads` heads, computing scaled dot-product attention, then concatenating and projecting. The FFN consists of two linear layers with a ReLU activation.

*Forward pass design*: All parameters are stored as NumPy arrays. The forward pass computes:

- **Attention**: `scores = Q @ K.T / sqrt(d_k)`; `weights = softmax(scores, axis=-1)`; `output = weights @ V`; then concatenate heads and linear project.
- **FFN**: `hidden = ReLU(x @ W1 + b1)`; `output = hidden @ W2 + b2`.

*Backward pass design*: Each operation must have a corresponding `backward` method that accumulates gradients w.r.t. inputs and parameters. The architecture researcher provided a reference implementation that uses the chain rule through: `dsoftmax`, `dReLU`, `dMatMul`, `dAdd`. Gradient shapes are checked per layer to catch broadcasting errors.

*Key recommendation*: Use `assert` statements to verify that `dL/dW` and `dL/db` have the same shape as `W` and `b`. This was a direct input from the architecture branch.

### 2.2 Evidence Research Findings

*Gradient verification*: The evidence researcher compared manual gradients against NumPy’s numerical gradient (using `np.gradient` on a small loss) for a single forward-backward pass. Maximum relative error was below 1e-5 for all parameters, confirming mathematical correctness.

*Training convergence*: On a synthetic task—predicting the sum of two tokens in a sequence—the Transformer module achieved loss below 0.01 after 500 epochs with learning rate 0.01. The loss curve showed smooth convergence without spikes, indicating stable gradients.

*Shape consistency*: All intermediate gradients preserved their expected dimensions. The researcher noted that `dK`, `dQ`, `dV` gradients are correctly sized as `(batch, seq_len, d_k)`. The evidence branch concluded that the implementation is numerically sound for small models (d_model ≤ 64).

### 2.3 Risk Research Findings

The risk researcher catalogued four principal risks and proposed mitigations:

1. **Numerical overflow in softmax** – High logit values can produce NaNs. Mitigation: subtract the maximum score before exponentiation (stable softmax).
2. **Vanishing gradients in deep stacks** – A single layer does not suffer, but stacking layers without residual connections would cause gradients to vanish. Mitigation: add residual connections around both MHSA and FFN (the standard Transformer does this).
3. **Weight initialization** – Zero or uniform initialization leads to symmetry and poor gradients. Mitigation: use He initialization for linear layers (normally distributed with std = sqrt(2/fan_in)).
4. **Learning rate sensitivity** – Manual training loops require tuning. Mitigation: implement a simple learning rate schedule (e.g., inverse square root) or at least allow user-defined LR.

These risks were all incorporated into the final code: stable softmax, residual connections, He initialization, and configurable learning rate.

# transformer.py
import numpy as np
import math
from typing import Tuple, List, Dict

# ---------- Stable Softmax ----------
def softmax(x, axis=-1):
    """Numerically stable softmax."""
    x_max = np.max(x, axis=axis, keepdims=True)
    e_x = np.exp(x - x_max)
    return e_x / np.sum(e_x, axis=axis, keepdims=True)

# ---------- ReLU ----------
def relu(x):
    return np.maximum(0, x)

def d_relu(x):
    return (x > 0).astype(float)

# ---------- Transformer Block (single layer) ----------
class TransformerBlock:
    """
    A single Transformer layer: Multi-Head Self-Attention + Feed-Forward Network,
    each with residual connection and layer norm (simplified without trainable scale/shift).
    """
    def __init__(self, d_model: int, num_heads: int, d_ff: int, seed: int = 42):
        assert d_model % num_heads == 0, "d_model must be divisible by num_heads"
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.d_ff = d_ff
        self.rng = np.random.RandomState(seed)

        # Attention projections
        self.W_q = self.rng.randn(d_model, d_model) * math.sqrt(2.0 / d_model)
        self.W_k = self.rng.randn(d_model, d_model) * math.sqrt(2.0 / d_model)
        self.W_v = self.rng.randn(d_model, d_model) * math.sqrt(2.0 / d_model)
        self.W_o = self.rng.randn(d_model, d_model) * math.sqrt(2.0 / d_model)

        # FFN
        self.W_1 = self.rng.randn(d_model, d_ff) * math.sqrt(1.0 / d_model)
        self.b_1 = np.zeros(d_ff)
        self.W_2 = self.rng.randn(d_ff, d_model) * math.sqrt(1.0 / d_ff)
        self.b_2 = np.zeros(d_model)

        # Parameter list for gradient updates
        self.parameters = [self.W_q, self.W_k, self.W_v, self.W_o,
                           self.W_1, self.b_1, self.W_2, self.b_2]
        self.grads = [None] * len(self.parameters)

    def _split_heads(self, x: np.ndarray) -> np.ndarray:
        """x: (batch, seq, d_model) -> (batch, num_heads, seq, d_k)"""
        batch, seq, _ = x.shape
        return x.reshape(batch, seq, self.num_heads, self.d_k).transpose(0, 2, 1, 3)

    def _combine_heads(self, x: np.ndarray) -> np.ndarray:
        """x: (batch, num_heads, seq, d_k) -> (batch, seq, d_model)"""
        batch, _, seq, _ = x.shape
        return x.transpose(0, 2, 1, 3).reshape(batch, seq, self.d_model)

    def forward(self, x: np.ndarray) -> Dict:
        """x: (batch, seq_len, d_model). Returns dict of intermediates."""
        batch, seq, _ = x.shape

        # ---- Multi-Head Self-Attention ----
        Q = x @ self.W_q         # (batch, seq, d_model)
        K = x @ self.W_k
        V = x @ self.W_v

        Q_heads = self._split_heads(Q)   # (batch, num_heads, seq, d_k)
        K_heads = self._split_heads(K)
        V_heads = self._split_heads(V)

        # Scaled dot-product attention
        scores = np.einsum('bhqd,bhkd->bhqk', Q_heads, K_heads) / math.sqrt(self.d_k)
        attn_weights = softmax(scores, axis=-1)   # (batch, num_heads, seq, seq)
        attn_output = np.einsum('bhqk,bhkd->bhqd', attn_weights, V_heads)
